# /models/ — 建模 + 求解器验证

这里放两类东西：

1. **标准模型**：作业/例题的完整数学模型（决策变量含义、目标函数、约束及说明），以 Python 脚本形式保存
2. **求解器验证**：用 scipy（HiGHS）求解，和手算的单纯形表结果对照

> 求解器只用来**核对**，不替代手算。考试要手算单纯形表；而且求解器不会告诉你"有无穷多最优解"或"退化"，这些仍要看最终单纯形表的检验数。

## 用法

```bash
pip install scipy numpy        # 第一次使用前
cd models
python3 ch01-课件例题验证.py
```

新建题目时复制下面的模板：

```python
from lp_check import solve_lp

solve_lp(
    "max", [2, 3],                                  # 方向、目标函数系数
    [([1, 2], "<=", 8,  "设备台时"),                # (系数, 方向, 右端项, 说明)
     ([4, 0], "<=", 16, "银锭用量"),
     ([0, 4], "<=", 12, "金锭用量")],
    names=["x1", "x2"],
    title="第一章 例1", expect=14,                  # expect = 手算得到的最优值
)
```

自由变量（无非负限制）用 `bounds=[(0, None), (None, None), ...]`。
